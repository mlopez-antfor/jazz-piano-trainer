# Jazz Piano Trainer

App web para practicar voicings de jazz con un teclado MIDI (pensada para iPad con MIDIWeb Browser).

Las partituras (MusicXML) y los audios de acompañamiento los importa cada usuario; no forman parte de este repositorio.

## Créditos

Sonido de piano: **Salamander Grand Piano V3**, de Alexander Holm, con licencia

Detalles en `sonidos/piano/LEEME.txt`.
